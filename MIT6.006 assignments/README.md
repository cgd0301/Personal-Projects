# MIT 6.006 — Introduction to Algorithms (Fall 2011)

## Briefing

This is a collection of MIT6.006 (Introduction to Algorithm Fall 2011) assignments accomplished independently.

There might be some slight mistakes through the assignments. For official answers, please check on the MIT OpenCourseWare website. These files are only intended to record personal learning progress.

Some basic data sturctures and algorithms were employed in the assignment, including but not limited to binary search tree, hashing, AVL Tree, Dijkstra, dynamic programming and so on.

## Problem sets

| PS  | Topics                                                    |
| --- | --------------------------------------------------------- |
| 1   | Asymptotics, recurrences, 2D peak finding                 |
| 2   | Recursion trees, event-driven circuit simulation (heaps)  |
| 3   | Augmented BSTs, range queries, sweep-line layout          |
| 4   | Hashing, rolling hashes, DNA substring matching           |
| 5   | Big-integer arithmetic, Karatsuba, modular exponentiation |
| 6   | Graphs, two-way BFS, topological sort, Dijkstra           |
| 7   | DP: seam carving, knapsack                                |
